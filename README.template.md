## 🗺️ 东京找厕所实用攻略

东京虽然厕所很多，但真正方便找到的厕所还是有一些规律的。

### 1. 🚉 优先找车站

日本车站基本都会有厕所。

尤其是：

* JR 各站
* 东京 Metro
* 都营地下铁
* 私铁车站

如果只是临时急着找厕所，**直接进最近的车站通常是最快的方法之一。**

---

### 2. 🏪 便利店不一定能随便使用

日本便利店以前经常可以直接使用厕所，但现在不同店铺的规定差异很大。

常见情况：

* 有些店厕所直接开放
* 有些店需要向店员说明
* 有些店仅限购买商品的顾客
* 有些店已经停止提供厕所

所以不要把便利店厕所当成绝对可靠的选择。

---

### 3. 🏬 商场 / 百货公司是最稳的选择

如果你正在购物、逛街或者下雨天，可以优先寻找：

* 百货公司
* 大型商场
* 商业综合体
* 电器城
* 大型书店

这些地方通常厕所数量比较多，而且：

* 空间更大
* 清洁程度较高
* 多功能厕所较常见
* 女性厕所通常比较充足

---

### 4. 🌳 公园厕所

东京很多公园都有公共厕所。

如果你正在：

* 代代木公园
* 涩谷
* 原宿
* 新宿
* 惠比寿
* 青山

附近散步，可以直接搜索附近的：

> `公衆トイレ`

或者：

> `トイレ`

Google Maps 通常可以直接找到附近厕所。

---

### 5. 📱 Google Maps 搜索技巧

最简单的方法：

在 Google Maps 搜索：

`トイレ`

或者：

`公衆トイレ`

也可以搜索：

`toilet`

然后根据距离选择最近的厕所。

## 📍 本项目的数据结构

本项目使用 JSON 管理厕所信息。

数据文件：

```text
data/toilets.json
```

README 不直接手工维护厕所列表，而是通过 Python 自动生成。

项目结构：

```text
tokyo-toilet-guide/
├── README.md
├── README.template.md
├── generate_readme.py
├── data/
│   └── toilets.json
└── images/
```

### 为什么这样做？

以后如果需要：

* 添加厕所
* 删除厕所
* 修改排名
* 修改介绍
* 修改 Google Maps 链接
* 修改设计师
* 修改标签

只需要修改：

```text
data/toilets.json
```

然后运行：

```bash
python generate_readme.py
```

即可自动重新生成 `README.md`。

## 🧩 数据字段说明

每个厕所的数据大致包含：

| 字段              | 说明             |
| --------------- | -------------- |
| `id`            | 唯一 ID          |
| `rank`          | 推荐排名           |
| `name.zh`       | 中文名称           |
| `name.ja`       | 日文名称           |
| `type`          | 厕所类型           |
| `designer`      | 设计师 / 设计团队     |
| `designer_en`   | 设计师英文名         |
| `address`       | 地址             |
| `google_maps`   | Google Maps 链接 |
| `official_page` | 官方介绍页面         |
| `tags`          | 标签             |
| `description`   | 厕所介绍           |

## 🔄 如何更新 README

修改：

README.md
