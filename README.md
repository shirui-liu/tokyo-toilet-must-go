## 🏆 东京特色厕所

东京有很多厕所不仅仅是「解决生理需求」的地方。

从建筑大师设计的公共厕所，到隐藏在酒店、商业设施里的豪华厕所，这份榜单主要收录：

* 🏛️ 建筑设计值得看的厕所
* 🎨 艺术感、视觉效果特别的厕所
* 📸 适合打卡拍照的厕所
* 🚻 设施、隐私性或使用体验优秀的厕所
* ⭐ 值得顺路去看的特色厕所

### 榜单说明

🥇🥈🥉 为个人推荐排名。

⭐ 为特色推荐，不代表具体排名。

> 本榜单中的排名主要参考「值得专程去一趟」的程度、设计特色以及实际体验。

### 🥇 代代木深町小园彩色透明厕所

**坂 茂｜Shigeru Ban**

坂茂设计的彩色透明玻璃厕所。未使用时透明可见内部，一旦关门便变成磨砂不透明。夜晚亮灯后像公园里的温暖灯笼，橙、粉、紫的配色非常适合拍照，也是电影《完美的日子》的相关取景地。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=代々木深町小公園トイレ)

`坂茂` `透明玻璃` `彩色` `夜景` `电影取景地`

---

### 🥈 锅岛松涛公园森林木屋厕

**隈 研吾｜Kengo Kuma**

隈研吾设计的森林中的厕所村。5栋杉木板小屋错落分布，以随机角度的杉木板百叶窗包裹，并通过「森のコミチ」连接起来，仿佛消失在公园绿意之中。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=鍋島松濤公園トイレ)

`隈研吾` `木造` `森林` `森系` `建筑打卡`

---

### 🥉 目黑雅叙园豪华卫生间

目黑雅叙园著名的豪华卫生间。朱漆、金箔、螺钿花鸟装饰与日式绘画铺满空间，内部甚至有流水与朱漆小桥，整体更像一座小型日式宫殿而非普通公共卫生间。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=ホテル雅叙園東京)

`目黑雅叙园` `日式宫殿` `螺钿` `金箔` `朱漆` `豪华`

---

### ⭐ 裏参道公厕

**马克·纽森｜Marc Newson**

Marc Newson设计的公共厕所。建筑采用铜板葺的传统屋顶形式与石垣元素，内部则使用明亮的绿色无缝设计，传统外观与现代室内形成鲜明反差。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=裏参道公衆トイレ)

`Marc Newson` `铜材质` `绿色` `未来感` `高架下`

### ⭐ 神宫通公园公厕

**安藤忠雄｜Tadao Ando**

安藤忠雄设计的「あまやどり」。圆形建筑配合纵向格栅，让自然光和空气进入内部，同时通过大屋檐形成可以避雨的空间。清水混凝土与光影构成极具安藤忠雄风格的建筑体验。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=神宮通公園トイレ)

`安藤忠雄` `清水混凝土` `圆形` `自然光` `极简`

### ⭐ 西参道「器・泉」公厕

**藤本壮介｜Sou Fujimoto**

藤本壮介设计的白色弧形公共厕所。建筑曲线以器皿为灵感，中央设置大型洗手池，5个水龙头高度各不相同，从儿童到成人及轮椅使用者都能方便使用。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=西参道公衆トイレ)

`藤本壮介` `白色` `水` `洗手池` `无障碍`

### ⭐ 笹塚绿道公厕

**小林纯子｜Junko Kobayashi**

小林纯子设计的「まちあかりのトイレ」。不同高度的圆筒形建筑配上巨大的黄色椭圆屋檐，外墙圆窗会映出兔子图案。建筑使用耐候性钢板，专门针对京王线高架下的压迫感进行设计。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=笹塚緑道公衆トイレ)

`小林纯子` `高架下` `耐候性钢板` `黄色屋檐` `兔子`

### ⭐ 惠比寿公园迷宫公厕

**片山正通 / Wonderwall｜Masamichi Katayama / Wonderwall**

片山正通 / Wonderwall设计的「Modern Kawaya」。15道混凝土墙以错落方式排列，形成类似迷宫的空间，同时划分出男厕、女厕和无障碍厕所。灵感来自日本古代厕所「川屋」，建筑与周围公园环境自然融合。

📍 [Google Maps](https://www.google.com/maps/search/?api=1&query=恵比寿公園トイレ)

`片山正通` `Wonderwall` `迷宫` `混凝土` `Modern Kawaya`

## 🗺️ 东京找厕所实用攻略

东京虽然厕所很多，但真正方便找到的厕所还是有一些规律的。

### 1. 🚉 优先找车站

日本车站基本都会有厕所。

尤其是：

* JR 各站
* 东京 Metro
* 都营地下铁
* 私铁车站

如果只是临时急着找厕所，**直接进最近的车站通常是最快的方法之一。**

---

### 2. 🏪 便利店不一定能随便使用

日本便利店以前经常可以直接使用厕所，但现在不同店铺的规定差异很大。

常见情况：

* 有些店厕所直接开放
* 有些店需要向店员说明
* 有些店仅限购买商品的顾客
* 有些店已经停止提供厕所

所以不要把便利店厕所当成绝对可靠的选择。

---

### 3. 🏬 商场 / 百货公司是最稳的选择

如果你正在购物、逛街或者下雨天，可以优先寻找：

* 百货公司
* 大型商场
* 商业综合体
* 电器城
* 大型书店

这些地方通常厕所数量比较多，而且：

* 空间更大
* 清洁程度较高
* 多功能厕所较常见
* 女性厕所通常比较充足

---

### 4. 🌳 公园厕所

东京很多公园都有公共厕所。

如果你正在：

* 代代木公园
* 涩谷
* 原宿
* 新宿
* 惠比寿
* 青山

附近散步，可以直接搜索附近的：

> `公衆トイレ`

或者：

> `トイレ`

Google Maps 通常可以直接找到附近厕所。

---

### 5. 📱 Google Maps 搜索技巧

最简单的方法：

在 Google Maps 搜索：

`トイレ`

或者：

`公衆トイレ`

也可以搜索：

`toilet`

然后根据距离选择最近的厕所。

## 📍 本项目的数据结构

本项目使用 JSON 管理厕所信息。

数据文件：

```text
data/toilets.json
```

README 不直接手工维护厕所列表，而是通过 Python 自动生成。

项目结构：

```text
tokyo-toilet-guide/
├── README.md
├── README.template.md
├── generate_readme.py
├── data/
│   └── toilets.json
└── images/
```

### 为什么这样做？

以后如果需要：

* 添加厕所
* 删除厕所
* 修改排名
* 修改介绍
* 修改 Google Maps 链接
* 修改设计师
* 修改标签

只需要修改：

```text
data/toilets.json
```

然后运行：

```bash
python generate_readme.py
```

即可自动重新生成 `README.md`。

---

## 🧩 数据字段说明

每个厕所的数据大致包含：

| 字段              | 说明             |
| --------------- | -------------- |
| `id`            | 唯一 ID          |
| `rank`          | 推荐排名           |
| `name.zh`       | 中文名称           |
| `name.ja`       | 日文名称           |
| `type`          | 厕所类型           |
| `designer`      | 设计师 / 设计团队     |
| `designer_en`   | 设计师英文名         |
| `address`       | 地址             |
| `google_maps`   | Google Maps 链接 |
| `official_page` | 官方介绍页面         |
| `tags`          | 标签             |
| `description`   | 厕所介绍           |

## 🔄 如何更新 README

修改：

