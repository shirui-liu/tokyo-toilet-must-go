## 🏆 東京の特色あるトイレ

東京には、単なる「用を足す場所」にとどまらない、個性的なトイレがたくさんあります。

建築家が手がけた公衆トイレから、ホテルや商業施設にある豪華なトイレまで、デザイン性、話題性、実用性などの観点から、訪れる価値のあるトイレを紹介します。

### ランキングについて

🥇🥈🥉 は個人的なおすすめランキングです。

⭐ は特色のあるおすすめスポットで、順位はつけていません。

## 🗺️ 東京でトイレを探す実用ガイド

### 🚉 1. まず駅を探す

日本の駅には基本的にトイレがあります。

特に：

* JR
* 東京メトロ
* 都営地下鉄
* 私鉄

などの駅は、急にトイレを探す必要があるときに便利です。

---

### 🏪 2. コンビニのトイレは必ず使えるとは限らない

コンビニのトイレは店舗によって利用ルールが異なります。

例えば：

* 自由に利用できる
* 店員に声をかける必要がある
* 購入者のみ利用可能
* トイレ自体を設置していない / 利用停止中

といったケースがあります。

---

### 🏬 3. 商業施設・百貨店は比較的安心

買い物中や雨の日には、以下の施設を探すのがおすすめです。

* 百貨店
* 大型ショッピングモール
* 商業施設
* 家電量販店

トイレの数が多く、設備も比較的充実しています。

---

### 🌳 4. 公園の公衆トイレ

東京の多くの公園には公衆トイレがあります。

渋谷、原宿、代々木、恵比寿などを散策しているときは、

`公衆トイレ`

または

`トイレ`

で検索すると見つけやすくなります。

---

### 📱 5. Google Mapsで探す

Google Mapsで以下を検索すると、近くのトイレを探せます。

`トイレ`

`公衆トイレ`

`toilet`

## 📊 データについて

このプロジェクトでは、トイレの情報をJSONで管理しています。

```text
data/toilets.json
```

トイレの情報を変更した後、

```bash
python generate_readme.py
```

を実行すると、以下の3つのREADMEが自動生成されます。

* `README.md`
* `README.ja.md`
* `README.en.md`
